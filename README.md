# AI use
Data wrangling and analysis (`scripts/`): written by us. AI was used as a tutor: explaining pandas concepts, debugging errors, and suggesting short snippets (about 5–10 lines) that we read, understood and adapted.
App logic (`app.py`, `pages/`): game flow, scoring and data handling written by us, with the same kind of AI help.
Visual design (styling, layout polish, chart formatting): built with substantial AI assistance. We understand what each part does and how it fits into the app, but not necessarily every line of the styling code.
